# 📖 Personal Journal Manager

A simple, robust command-line interface (CLI) application written in Python to manage your daily journal entries. It allows you to write, view, search, and manage your personal journal notes stored safely in a local text file.

---

## 🚀 Features

* **Add New Entries (`1`)**: Automatically timestamps your entries and appends them to your journal file.
* **View All Entries (`2`)**: Displays your entire journal history cleanly.
* **Search Entries (`3`)**: Case-insensitive keyword or date-based search that filters and displays relevant journal blocks.
* **Delete All Entries (`4`)**: Safely removes the journal file with a confirmation prompt.
* **Robust Error Handling**: Handles missing files, permission errors, and empty inputs gracefully without crashing.

---

## 🛠️ Prerequisites

* Python 3.x installed on your system. No external libraries are required!
